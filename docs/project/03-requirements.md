# Project Requirements

## Functional Requirements

### Discussion

- **[FR-DISC-001]**: Registered user should be able to create a discussion.
- **[FR-DISC-002]**: The discussion creator should be able to set discussion visibility [public, private].
- **[FR-DISC-003]**: The discussion creator should be able to keep discussion in draft before publishing.
- **[FR-DISC-004]**: The registered user should be able to edit or delete a discussion.
- **[FR-DISC-005]**: Any person on internet registered or not registered should be able to see discussions posted.
- **[FR-DISC-006]**: Registered users should be able to follow discussions to keep them as separate.

## Non-Functional Requirements

### Discussion
- **[NFR-DISC-001]**: The discussion should not be just random text.
- **[NFR-DISC-002]**: The discussion must contain a clear question.
- **[NFR-DISC-003]**: The discussion should not be just random text.
- **[NFR-DISC-004]**: User should not be able to edit or delete discussion after 1 hour of publishing.
- **[NFR-DISC-005]**: User should not be able to private discussion after 1 hour of setting it as public.
